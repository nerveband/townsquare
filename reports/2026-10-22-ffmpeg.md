## What changed
- Bundled static ffmpeg and ffprobe 9.0.2 (Martin Riedl builds, GPL v3) in `Townsquare.app/Contents/Resources/bin`, Apple silicon and Intel in one file each, ad-hoc signed. `scripts/fetch-ffmpeg.sh` downloads them, checks pinned SHA-256 sums and caches them; `scripts/package.sh` assembles them and fails if either links anything outside `/usr/lib` and `/System/Library`.
- License notices: `Contents/Resources/ffmpeg-licenses/` has NOTICE.txt (source links, written offer, how to replace), COPYING.GPLv3, versions-arm64.txt, versions-amd64.txt. Source in repo: `third_party/ffmpeg/`.
- Lookup (`wa.ToolSource`): `TOWNSQUARE_FFMPEG_DIR`, then the app's own folder (also found from `~/.townsquare/bin` after a self-update via /Applications and ~/Applications), then PATH and Homebrew only when the bundled copy is missing. A bundled copy that is broken is reported, not silently replaced.
- Health check (`wa.CheckFFmpeg`): `-version`, PNG to JPEG with the real image args, 1 second H.264 + AAC video with the real video args, voice note to Opus, ffprobe reads the video back. Reports path, version, error text. Runs at start and every 10 minutes; `GET /api/v1/ffmpeg` (CLI `townsquare ffmpeg get`) runs it now; `GET /status` carries the latest result; Settings > General shows it with a Test again button; `townsquare doctor` has an `ffmpeg` check and exits 21 when it fails.
- Convert and the check share one set of encode arguments (`imageEncode`, `videoEncode`, `voiceEncode`), so they cannot drift.

## Decisions and risks for Ashraf
1. Download size: the Mac dmg grew from about 45 MB to 174 MB (two universal binaries). Windows exe, Linux debs and plain binaries still use the system ffmpeg (the deb Recommends apt's ffmpeg; no Windows installer to put files in); they get the new health check but no bundle. Linux static builds exist (same builder) if wanted.
2. GPL: the bundle is GPL v3 (libx264, libx265). Townsquare is AGPL v3, which is compatible, and ffmpeg runs as a separate program. NOTICE.txt contains a 3 year written offer for the source and links to upstream, which commits you to supply it on request. Not legal advice.
3. Self-updates only replace the Townsquare program, so existing installs get the bundled ffmpeg only by installing the new Mac app download.
4. Screenshots in docs/screenshots were not refreshed (small new row in Settings > General, checked on desktop and phone width in demo mode).
