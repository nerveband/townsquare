# Townsquare brand assets

| File | Use |
|---|---|
| `icon-1024.png` | Master app icon, transparent rounded square |
| `icon-fullbleed-1024.png` | Square with no transparency, for iOS and Android (they round the corners) |
| `macos-1024.png` | macOS icon grid (824 px tile with shadow on a 1024 canvas) |
| `Townsquare.icns` | macOS app icon bundle |
| `favicon.svg` | Simplified drawing for 16 to 32 px (browser tab) |

Colors: sky `#1673E6`, navy ink `#0E2A47`, grass `#2DB34E`, sun `#FFD21F`, cream `#F6EEDA`.
Web copies live in `web/ui/public/`.
